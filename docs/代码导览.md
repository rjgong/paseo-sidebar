# 代码导览

## 模块关系

```text
Paseo 客户端
  index.client.tsx
    ├─ TasksSurface：任务侧栏
    │    ├─ BookReadingCard：EPUB 阅读
    │    ├─ MusicBeeBar：桌面本机音乐控制
    │    ├─ DailyWorkload：当天活动与工作量
    │    └─ TaskActionsModal：编辑任务
    └─ EvaDirectCard：通知会话中的交互卡片

共享协议 shared/*.ts
  defineRpc + Zod 输入输出约束

Paseo 服务端
  index.server.ts
    ├─ notion.ts / complete.ts：任务读写与完成回执
    ├─ book-reading.ts → book_reader.py：书库与阅读位置
    ├─ daily-workload.ts：读取预先生成的活动记录
    ├─ eva-direct.ts / eva.ts：通知、回复与会话操作
    └─ usage.ts / phone.ts / audio.ts：设备数据接入
```

## 任务列表怎样刷新

`TasksSurface` 用 TanStack Query 缓存任务列表，每分钟重新读取一次。另一个轻量 RPC 每五秒检查刷新标记文件的修改时间与大小；外部脚本写完任务后触碰这个文件，面板便重新拉取列表。

新增、编辑、移出计划或完成任务后，客户端使任务缓存失效。完成操作会先把对应行从当前画面隐藏，再等下一次查询确认结果；非通知任务还会显示八秒的完成回执。

任务数据由 `server/notion.ts` 转为 `shared/contracts.ts` 的统一结构。Notion 属性名称、任务标签、计划标签和时区边界直接写在实现里。参考时应连同分组规则一起阅读 `client/model.ts`。

## 阅读与音乐

`BookReadingCard` 通过 `tasks.book-reading` 调用服务端。`book-reading.ts` 启动同目录的 Python 脚本；脚本读取 Anx SQLite 数据库和 EPUB 文件，解析章节、分页并维护独立的侧栏阅读状态；Anx 数据库只读，位置同步由 Anx 导入侧栏。Python 使用 `lxml`，书库及状态目录可以通过 `SIDEBAR_ANX_ROOT` 和 `SIDEBAR_BOOK_STATE_DIR` 覆盖。

MusicBee 在桌面客户端直接访问 `http://127.0.0.1:18877/rpc`。`client/musicbee-local.ts` 从宿主提供的 `globalThis.paseoMusicBee` 获取本机令牌、请求启动播放器；令牌本身不写进源码。桌面宿主桥接和本机 MusicBee 服务不在此包内。

## 当天活动怎样显示

`server/daily-workload.ts` 读取外部流程生成的巡视分类记录，按自然日整理成每小时六个十分钟格子，并汇总活动明细和各方向成果。

`DailyWorkload` 每分钟读取结果，展示“课题、兴趣、系统、阅读、事务”五个方向的当天累计；小时格默认取最近四个有记录小时，可展开更多记录或打开明细。协议里的 `points` 是工作量评价值，供此视图汇总使用。

## 通知怎样进入会话

`server/eva-direct.ts` 从通知任务文件读取卡片，创建或恢复关联会话，持久化卡片和选项状态。`EvaDirectCard` 在会话面板中展示正文、背景、选项和回复输入框。

选项可以创建会话、把指令发送给已有会话、完成或关闭待办、归档会话等。文字回复通过共享 RPC 传给服务端。事件标识、串行处理与持久化记录用于重复请求处理和状态恢复。卡片来源名称、模型标识及会话命名规则保留直接写在代码里的形式，示例模型标识为 `example/assistant`。

`client/links.tsx` 将卡片中的网址与示例工作区路径做成可点击链接。桌面使用宿主打开路径；移动端读取文件并交给设备上的应用打开，这部分依赖定制的宿主接口。

## 包外依赖与示例路径

| 示例值或依赖 | 在代码中的用途 |
| --- | --- |
| `/srv/paseo-sidebar/config.json` | Notion 配置；也可通过 `PASEO_TASKS_CONFIG` 指定 |
| `/srv/paseo-sidebar/scripts/` | 刷新标记及通知、回复记录等外部脚本 |
| `/srv/paseo-sidebar/assistant/` | 通知卡片、活动分类和设备记录目录 |
| `/srv/books/anx/` | Anx 数据库及 EPUB 文件 |
| `/srv/paseo-sidebar/data/book-reader/` | 侧栏阅读状态 |
| `/home/example/.paseo/agents/` | Paseo 会话记录目录 |
| `/usr/local/bin/paseo` | 会话和工作区归档使用的 CLI 路径 |
| `P:\` | 桌面端文件打开逻辑中的示例盘符 |
| Notion 数据库 | 属性结构需要与 `server/notion.ts` 一致 |
| Paseo 定制宿主接口 | MusicBee、本地文件打开与移动端能力 |

这些路径用于展示原实现的连接方式。包内保留调用端，包外的数据生成器、通知系统、桌面补丁、手机应用及真实服务配置未一起复制。

## 给 LLM 的参考方式

可以先阅读 `index.client.tsx`、`index.server.ts` 与 `shared/`，确认插件注册和 RPC 约定，再选择一个需要复用的模块。任务列表、阅读器、活动视图与通知卡片各有独立的数据流；迁入其他项目时，可沿着对应的数据流替换宿主接口、数据来源、路径和配置。
