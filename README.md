# Paseo 任务侧栏参考实现

一份从日常使用的 Paseo 插件中整理出的源码示例，供开发者和 LLM 参考侧栏布局、插件 RPC、任务操作和通知交互的实现方式。

代码保留了原有的直接文件读取、固定路径和外部脚本调用。个人路径和配置标识已替换为示例值，未附带运行数据与凭证。它是一份实现参考，运行它还需要补齐对应的服务和客户端扩展。

## 包含的功能

| 功能 | 行为 |
| --- | --- |
| 任务与计划 | 从 Notion 读取任务，按计划和标签分组；新增、改名、调整标签与时间、移出计划、完成和删除 |
| 近期日程 | 显示未来七天的安排，标记临近与逾期任务 |
| 完成回执 | 完成后立即隐藏任务，短暂展示结果；支持释放下一项顺序任务 |
| EPUB 阅读 | 从 Anx 书库读取 EPUB，在侧栏阅读、切换书籍、翻页和同步阅读位置 |
| MusicBee | 桌面端通过本机接口控制播放、播放列表、进度与循环模式 |
| 当天活动 | 展示全天各方向工作量、每小时活动格子与明细，默认显示最近四个有记录小时 |
| 通知卡片 | 在会话面板展示正文与选择题，处理选项、文字回复、待办完成和会话跳转 |
| 设备接入 | 保留手机使用记录、通知与短信、文件分块及音频上传的辅助 RPC |

## 从哪里看

- [代码导览](docs/代码导览.md)：模块关系、数据流和外部依赖。
- [客户端入口](plugin/index.client.tsx)：侧栏、会话面板和工作区按钮的注册。
- [任务面板](plugin/client/TasksSurface.tsx)：主要侧栏布局与任务交互。
- [服务端入口](plugin/index.server.ts)：RPC 处理函数的注册。
- [共享协议](plugin/shared/contracts.ts)：任务与设备 RPC 的输入输出约定。
- [配置示例](config.example.json)：仅含占位值。

`plugin/` 中是整理后的源码，使用 React、React Native、TanStack Query、Zod 和 Paseo Plugin SDK；EPUB 解析由 Python 辅助脚本完成。插件元数据保留原来的名称和版本。

## 范围与验证

这份源码不包含巡光驻地、视频转写阅读、收藏阅读架、自动补齐阅读任务、旧积分与奖励兑换、旅程地图和研究进度地图。对应的组件、服务端注册及协议引用也已移除。

整理后的 TypeScript 源码通过 `npm run typecheck`；Python 脚本通过语法检查。未进行完整环境部署或端到端运行验证。依赖锁文件保留，`node_modules`、个人配置、数据库、阅读状态、消息、录音和历史备份均未打包。
